# auto-remove-paywall
simple tampermonkey script to auto remove paywalls with tampermonkey &amp; archive.is!

how to use: 
- install tampermonkey
- create a custom script with this code
- enjoy!

whenever you go on your fav news site it should redirect you and remove the paywalls automatically

if you want to add another news site just go to the site, inspect element the paywall, copy the html code, go to claude.ai and ask it to edit the code for you to include paywall detection for the html for that site

and make a pull request 

enjoy:)
